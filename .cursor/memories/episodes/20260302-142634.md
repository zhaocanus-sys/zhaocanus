# 对话摘要

创建report_design_principles_kb.md报表设计原则知识库，涵盖7大章节：结构规范/员工分析规范/诊断深度/建议输出/视觉布局/各业务体定位模板/历次优化记录。优化建信报表：新增业务定位描述（建信=信任传递桥梁+5个关注重点）、员工TOP5/BOTTOM5深度分析（全部过程字段+综合评分+为什么好/问题在哪+可复制性分析）。

## 关键决策

- 建立report_design_principles_kb.md知识库
- 报表顶部必须有业务定位描述+高业绩关注重点
- 员工分析必须含全部过程字段+评分+分析评价+可复制性
- 撤销最多3条建议限制
