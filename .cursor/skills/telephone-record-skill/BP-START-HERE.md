# 给 BP 的使用说明

不要输入命令，按顺序双击下面 3 个文件即可：

1. `01-install.command`
2. `02-doctor.command`
3. `03-query.command`

## 说明

- 第 1 步会自动安装依赖并做安装后自检。
- 第 2 步会诊断数据库连通性，告诉你是依赖问题、网络问题还是权限问题。
- 第 3 步会展示录音类型列表和查询示例。

## 如果失败

不要自己判断原因，直接把弹出的窗口完整截图发给管理员。

尤其是下面两种情况：

- 如果提示"数据库连接失败"，通常需要连接公司内网或 VPN。
- 如果提示某张表不可访问，通常是数据库用户权限问题。
