# 顾景舟印章款识图谱（鉴定对照库）

> 来源：赵总提供的三页「顾景舟(洲)印章款识」对照图 + 顾景舟本人 1984 年手书印谱说明。  
> 用途：鉴定时将待测壶的底款、盖内款、把内/把下款与本图谱**逐字比对字形、布局、刀法、钤印深度**，并结合 [seal-chronology.md](seal-chronology.md) 核对年代。

## 一、顾景舟自证印谱（1984-07-02）

## 二、底款 / 盖内 / 壶身钤印全录

以下整理自第一、二页对照图（共约 28 种印文变体，含重复字形不同版本）。

### A. 姓名印（核心款）

| 印文 | 字形特征 | 大致时期 | 常见位置 |
|------|----------|----------|----------|
| **顾景舟印** | 四字篆印，布局匀称，笔画劲挺；有多版（宽扁/方正/紧凑） | 名改「景舟」后 | 底款、盖内 |
| **顾景舟** | 三字或四字（无「印/制」），字形略长 | 中后期 | 底款、盖内 |
| **顾景洲印** | 「洲」字款，早期用名 | **1932–约1948 前** | 底款 |
| **景舟** | 二字篆印，竖排或横排；有方圆多版 | 全生涯 | 盖内、把下、底款 |
| **景舟手制** | 四字，强调手工 | 中期 | 底款 |
| **景舟制陶** | 四字，见 1984 印谱 | **1980 年代后常用** | 底款 |
| **顾** | 单字小章 | 各期 | 把下、壶把根部 |

> **注意**：市场仿品最高频伪造「**顾景舟制**」四字款；本图谱标准件多为「**顾景舟印**」「**景舟制陶**」「**景舟**」，字形、边框、笔画粗细须与具体版本逐一对照，不可混为一谈。

## 四、钤印位置与配套习惯

| 位置 | 常见印文 | 鉴定动作 |
|------|----------|----------|
| **壶底正中** | 顾景舟印、景舟制陶、顾景舟、艺名章 | 拍正底微距，比对字形与边框 |
| **盖内心** | 顾景舟、景舟、顾景舟印 | 须与底款时代、风格配套 |
| **盖内近气孔** | 小椭圆章、景舟简款 | 看是否与盖钮/气孔位置协调 |
| **把下端 / 把内** | 景舟、顾 | 真品常有；仅有底款而无把/盖款需说明理由 |
| **壶身** | 闲章、刻款、合作书画 | 与器型年代、合作者生卒互证 |

**配套原则（非绝对，但作初鉴参考）**：

- 底款「顾景洲印」→ 不应配晚期「景舟制陶」盖款  
- 底款「荆山壶隐」→ 应处 1948 后中期语境  
- 底款「景舟制陶」→ 与 1984 印谱一致，多见于晚期光素器

## 五、泥色与钤印观感（图谱中的样本）

对照图涵盖多种泥色上的印痕，鉴定时注意：

| 泥色 | 印痕观感 |
|------|----------|
| 深巧克力紫泥 | 印文凹陷清晰，边缘利落，无胶质感 |
| 朱泥 / 红泥 | 印较浅时仍可见笔画，勿与浅刻混淆 |
| 梨皮砂 | 颗粒起伏导致印缘略「毛」，但字形不散 |
| 深色光面 | 警惕过深、过匀、边缘如机器压印的「假印」 |

## 六、仿品印章常见破绽（对照本图谱时重点找）

1. **字形走样**：「景」「舟」「顾」的篆书结构、留白比例与图谱任一版本均不合  
2. **一字多体混乱**：底款用晚期字，盖内用早期「洲」字  
3. **印框失真**：真品方章边框挺劲；伪款常圆角过软或四角过尖  
4. **深度机械感**：全印等深、无自然按压轻重  
5. **「顾景舟制」泛滥**：本图谱标准件以「印」「制陶」为主；遇「制」字款须格外比对具体字形是否与馆藏一致  
6. **只有底款**：盖内、把下全无，又无合理解释（如早期素款器）

## 七、鉴定操作流程（款识专项）

1. 拍摄：**底款、盖内、把内/把下** 各一张微距（自然光，避免反光过曝）  
2. 转录：逐字写出印文，标注篆书异体  
3. 在本图谱 **第二节 + 第三节** 找最接近的标准格  
4. 查 [seal-chronology.md](seal-chronology.md) 核年代是否匹配  
5. 与器型、泥色、工艺结论 **三角互证**  
6. 任一环节不合 → 款识项标「疑」，不得单独定真
