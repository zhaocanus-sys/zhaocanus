# 年代推断（视觉与旁证）

图像初鉴只能给**年代区间**，不能精确到年。须声明不确定性。

## 视觉年代指标

| 指标 | 偏老（数十年+） | 偏新（近 0–15 年） |
|------|----------------|-------------------|
| 包浆 | 层次自然，口沿、把部、盖钮有差异 | 通体过净或做旧过匀 |
| 泥色 | 沉稳，局部色差，无贼光 | 匀亮、蜡感、金属光过强 |
| 刻款 | 刀口内与表面氧化一致 | 刻口过新、颜色与胎面脱节 |
| 印款 | 深浅自然，边缘略圆钝（使用磨损） | 等深、锐利、机械感 |
| 磨损 | 足缘、把内、盖口有合理使用痕 | 全新或仅局部做旧 |
| 工艺语言 | 老工房工具痕迹、修坯风格 | 现代明针过滑、批量感 |

## 区间表述规范

| 表述 | 含义 |
|------|------|
| 近新 | 0–5 年 |
| 近年 | 5–15 年 |
| 当代 | 约 1990 年代至今 |
| 上世纪中后期 | 约 1960–1990 |
| 更早 | 需流传+仪器，不单凭图 |

## 仪器与机构（需实物）

| 方法 | 能做什么 | 局限 |
|------|----------|------|
| 热释光（TL） | 烧成年代区间 | 取样破坏、费用高 |
| 显微观察 | 颗粒、气泡、修补 | 需实验室 |
| 紫外 / 红外 | 修补、做旧痕迹 | 辅助 |
| 权威鉴定站 | 综合定论 | 宜兴、国检珠宝中心等 |

## 禁止

- 不凭泥色单一特征断言「清代」「民国」
- 不把「像老」等同于「顾景舟年代」
