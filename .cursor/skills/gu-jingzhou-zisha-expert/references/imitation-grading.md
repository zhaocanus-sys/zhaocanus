# 仿品分级体系（独立于真伪结论）

仿品亦有水平高低。定「非顾景舟」后，须另作**仿制等级**评估，避免一概贬为「假壶无价值」。

## 五级量表

| 等级 | 名称 | 特征 | 典型来源 |
|------|------|------|----------|
| **F5** | 臆造粗仿 | 形制离谱、泥料差、印款幼稚、一眼假 | 地摊批量货 |
| **F4** | 商品仿款 | 器型泛泛、常见「顾景舟制」、盖底同文、无把款 | 闲鱼批量店 |
| **F3** | 工房仿款 | 泥料尚可、成型完整、刻字整齐但缺神韵 | 宜兴工房定制 |
| **F2** | 技法仿 | 某几项接近真品（泥色/刻字/比例），形制或款识仍露馅 | 熟练技工、仿古订单 |
| **F1** | 高仿 | 形制、泥料、款识多项逼近，需上手+仪器+流传才能拆穿 | 极少数，仍非真品 |

**注意**：F1 高仿≠可能为真品；只表示仿造投入高。

## 仿制目的分类

| 类型 | 动机 | 价格逻辑 |
|------|------|----------|
| 冒名款 | 卖「顾景舟」名义 | 标价虚高，实际应按工艺壶折价 |
| 仿古器 | 卖形制与文人味 | 按工艺、泥料、作者（若可知）定价 |
| 商品壶 | 卖实用与外观 | 按工房等级与零售渠道定价 |

## 输出格式（仿品专项）

```markdown
## 仿品等级：F__（名称）
## 仿制类型：冒名款 / 仿古器 / 商品壶
## 仿制水平一句话：（与真品差距在哪几项）
## 制作作者推断：批量工 / 工房技工 / 熟练艺人 / 无法判断
```
