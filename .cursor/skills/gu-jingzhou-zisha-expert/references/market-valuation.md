# 市场估价指引（非顾景舟署名的工艺壶）

## 原则

1. **冒名款一律先剥离「顾景舟」溢价**，再按工艺壶定价  
2. 给**区间**（人民币），注明渠道、品相、是否全手  
3. 标明「零售参考 / 二手参考 / 拍卖不适用」  
4. 真顾景舟作品不在此表——见拍卖图录，通常百万级起

## 估价因子

| 因子 | 影响 |
|------|------|
| 泥料 | 原矿紫泥 > 商品泥；朱泥、底槽清加价 |
| 工艺分 | 见 craftsman-skill-rubric.md |
| 装饰 | 满刻、陶刻名家参与加价 |
| 品相 | 无裂、无修、配件全 |
| 容量 | 小品（80–150ml）收藏圈偏好 |
| 渠道 | 闲鱼二手约为零售价 40–70% |

## 非名款零售区间参考（2024–2026 大陆市场量级）

| 工艺等级 | 全手光素 | 刻字/花器 | 备注 |
|----------|----------|-----------|------|
| 批量机辅 | 80–300 | 150–500 | 旅游纪念品级 |
| 普通工房 | 300–800 | 500–1500 | 日常泡茶 |
| 中上工房 | 800–2500 | 1500–4000 | 泥料工艺可见 |
| 熟练艺人无职称 | 2000–6000 | 4000–12000 | 需口碑或工作室 |
| 工艺师 / 名家 | 另议 | 另议 | 不在仿品估价范围 |

## 冒名款折价规则

- 带「顾景舟制」等虚假名款：**不得按顾景舟行情**，且买家心理折价 30–50%（款识风险）
- 闲鱼来源：在以上区间再取**偏下限**

## 输出格式

```markdown
## 市场参考（按工艺壶，非顾景舟）
- 零售区间：¥___ – ¥___
- 闲鱼二手：¥___ – ¥___
- 说明：（泥料/工艺/装饰/品相因子）
- 若按顾景舟价：不适用 / 误导性标价风险
```
