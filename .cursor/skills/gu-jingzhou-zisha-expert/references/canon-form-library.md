# 顾景舟经典器型形制库

鉴定时先判定「属哪一路器型」，再与著录标准比对。器型不对，款识再像也难定真。

## 景舟石瓢（代表作）

| 要素 | 标准特征 | 常见仿品偏差 |
|------|----------|--------------|
| 身筒 | 上窄下丰梯形，抛物线，圆浑饱满 | 过直、过扁、比例失调 |
| 盖 | 平盖微鼓，口盖严密 | 盖墙厚薄不匀 |
| 钮 | **桥钮**，半明半暗椭圆过渡 | 圆钮、柱钮、**双孔平盖** |
| 足 | 三围棋足，等边三角 | 平底、柱足错位 |
| 流 | 直流，胥出自然渐粗 | 接痕生硬 |
| 把 | 外圆内平三角势 | 耳把过软、角度别扭 |
| 参考尺寸 | 大石瓢：高约 8 cm，宽约 18 cm | — |

## 秦权壶

| 要素 | 标准特征 | 常见仿品偏差 |
|------|----------|--------------|
| 身筒 | 秤砣形，上收下放，弧线稳重 | 过尖、过直 |
| 盖 | 截盖微鼓 | 平盖无弧度 |
| 钮 | **桥形钮**顺盖面拱起 | 双孔、无钮 |
| 把 | 顾式多龙把；亦有耳把变体 | 比例失衡 |
| 装饰 | 光素为主 | 满刻诗文（多为后加或商品壶） |
| 参考尺寸 | 馆藏例：高约 12 cm，长约 16.8 cm | — |

## 子冶石瓢 / 矮石瓢 / 平盖石瓢

- **子冶石瓢**：清瘦挺劲，柱足
- **矮石瓢**：身扁，口颈有改动
- **平盖石瓢**：压盖处理，桥钮较明

## 其他光素名器（简表）

| 器型 | 顾氏特点关键词 |
|------|----------------|
| 提壁壶 | 线面挺拔，盖墙高 |
| 仿古壶 | 肩线张力，口沿精神 |
| 僧帽壶 | 口沿曲线精准 |
| 上新桥 | 双层气孔，层次清晰 |
| 供春（仿） | 筋纹自然，不刻板 |

## 使用方式

1. 先定器型类目（石瓢 / 秦权 / 圆器 / 方器…）
2. 逐项勾选上表「标准 vs 偏差」
3. **任一项核心要素严重偏离**（如石瓢无桥钮）→ 形制项判「不合谱」，不进入款识定真
