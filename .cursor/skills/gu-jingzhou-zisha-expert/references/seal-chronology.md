# 顾景舟印章与款识年表

> 艺名演变：顾景洲 → 瘦萍/老萍 → 荆南山樵/荆山壶隐 → 顾景舟（约1948年后）

## 分期对照

| 时期 | 约略年份 | 主要印款 |
|------|----------|----------|
| 学艺期 | 1932起 | 墨缘斋、墨缘斋景堂制、景记、景洲、武陵逸人 |
| 上海期 | 1942起 | 自怡轩主人、得一日闲为我福、足吾所好玩而老焉、曼晞、曼晞陶艺 |
| 艰难岁月 | 1944起 | 瘦萍、老萍 |
| 与沪上书画家交往 | 1948起 | 荆南山樵、荆山壶隐；约此时期改「景舟」 |
| 带徒期 | 1955起 | 啜墨看茶（闲章） |
| 晚年成熟期 | 1984起 | 景舟七十后作、壶叟 |
| 最后阶段 | 1990年代 | 生于乙卯 |

## 底款常见形式

- 早期：景洲、景记、墨缘斋景堂制 等
- 中期：瘦萍、荆南山樵、顾景舟制（需结合具体字形版本）
- 晚年：**壶叟**、**景舟七十后作** 极为常见；「顾景舟制」亦见，但需与具体器型、合作书画年代互证

## 盖内款习惯

- 盖内常有姓名款，与底款呼应
- 伪品常见：底款、盖款同文「顾景舟制」，但字形与馆藏标准件不符
- 鉴定时须比对：笔画粗细、边框、四字间距、印泥堆积形态

## 刻款（非印章）

- 顾景舟书法功底深厚，行楷端秀，刀镌遒劲
- 常与吴湖帆、江寒汀、唐云、来楚生等合作题刻
- 铭文落款须与纪年（如「庚辰年秋月」「辛卯年」）及大师在世年份（1915–1996）交叉验证

## 年代推算示例

| 干支 | 对应公历（20世纪） | 顾景舟年龄 |
|------|-------------------|------------|
| 庚辰 | 1940 | 25岁 |
| 庚午 | 1930 / 1990 | 15岁 / 75岁 |
| 辛卯 | 1951 | 36岁 |

若铭文「辛卯年」而器型、泥色、印章却似晚期「壶叟」风格，则存在矛盾。
