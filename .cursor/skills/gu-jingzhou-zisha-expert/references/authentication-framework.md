# 顾景舟紫砂壶鉴定框架

## 一、造型（形）

### 真品倾向
- 壶身、盖、流、把、钮五部件比例协调，俯视呈同心圆或明确几何关系
- 线面转折干净，无「鼓包」「塌陷」
- 三弯一线：壶嘴、壶盖口沿、壶把上沿在一条水平线上（圆器经典标准）
- 盖口严密，盖墙与口沿内外间隙均匀
- 顾景舟作品常具「静中寓动」的韵律，非机械对称

### 疑伪信号
- 壶把与身筒角度别扭，重心不稳
- 盖钮与盖面比例失调
- 流口过高或过低，与盖口不在一线
- 同款器型在多角度照片中比例不一致（可能混图）

## 二、胎质（泥）

### 真品倾向
- 宜兴原矿紫砂：颗粒感细腻自然，有「金星」「云母」闪点
- 色泽沉稳温润，久用有包浆层次，非单一色块
- 断面（若有）致密坚致

### 疑伪信号
- 表面过于光滑如打蜡，或颜色发艳、发闷
- 通体色泽高度均匀，缺乏天然泥料层次
- 人为做旧：口沿、盖钮周围黑渍呈涂抹状

## 三、工艺（工）

### 真品倾向
- 流、把接痕经明针处理，过渡如「从壶身长出」
- 内壁整洁，刮底痕迹自然
- 出水孔：顾景舟作品孔眼通常规整；早期有单孔、多孔，需结合器型年代
- 盖钮气孔位置居中，孔壁整齐

### 疑伪信号
- 接痕处有明显补泥、指痕未处理
- 出水孔大小参差、排列随意（本图可见七孔略不规则，需结合整体）
- 把内、把下无款而底款却署大名（需核对时期习惯）

## 四、款识（款）

### 鉴定要点
1. **印章内容**是否与年代匹配（见 seal-chronology.md）
2. **篆书结构**：真款笔画劲挺，布局匀称；伪款常笔画臃肿、间距失衡
3. **钤印深度**：自然按压有深浅变化，非机械等深
4. **底款与盖款**：是否同属顾景舟某一时期的配套习惯
5. **刻款书法**：顾景舟本人书法端秀遒劲；铭文刀法需与同期作品比对

### 「顾景舟制」四字款
- 顾景舟在名改「景舟」后（约1948年后）确有使用含「景舟」印款
- 但市场仿品最常伪造的就是「顾景舟制」「顾景舟」
- **必须**与器型、泥色、工艺、流传交叉验证

## 五、流传与市场

| 来源类型 | 风险 |
|----------|------|
| 嘉德/保利/西泠等拍卖图录、可核验场次 | 相对低 |
| 博物馆著录、权威出版物 | 低 |
| 名家弟子旧藏、有连续传承记录 | 中低 |
| 民间二手平台、无证书、故事捡漏 | **极高** |

## 六、置信度规则

- **高**：多图款识工艺泥料一致 + 流传可信 + 与馆藏真品多项吻合
- **中**：工艺泥料尚可但来源存疑，或款识无法与图录比对
- **低**：仅1–2张图、来源为闲鱼等、款识与铭文年代矛盾、多图内容不一致
