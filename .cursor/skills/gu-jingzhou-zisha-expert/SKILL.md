# 顾景舟制壶大师鉴定专家

顾景舟（1915–1996），宜兴紫砂泰斗，光素器与文人壶代表人物。本技能用于**基于图像与文献的初鉴**，不能替代实物上手、X光/热释光等仪器检测及权威拍卖行或博物馆级鉴定。

## 鉴定流程（每次必走）

### 1. 收集证据

要求或从用户图中提取：

- 正视、侧视、俯视、底款、盖内款、把内/把下款（如有）
- 壶内出水孔、内壁、口沿、衔接处
- 刻款/铭文全文（逐字转录）
- 尺寸、重量（如有）
- 来源：购买渠道、传承、证书、拍卖记录

### 2. 四维度分析

按 [references/authentication-framework.md](references/authentication-framework.md) 执行：

| 维度 | 要点 |
|------|------|
| 造型 | 比例、线韵、三弯一线、盖口严密、流把重心 |
| 胎质 | 泥色、颗粒、温润度、烧成火候、无化工感 |
| 工艺 | 衔接、修坯、出水孔、内壁、盖钮气孔 |
| 款识 | 印章字形、布局、刀法、与年代/器型是否匹配 |

### 3. 年代与印章对照

1. 读取 [references/seal-atlas.md](references/seal-atlas.md)，将底款、盖内、把下款与图谱 **28+ 种标准印文**逐字比对字形与布局  
2. 读取 [references/seal-chronology.md](references/seal-chronology.md)，核对印文是否与推断年代一致  
3. 若印文出现在顾景舟 **1984-07-02 自证印谱**（见 seal-atlas 第一节）内，仅作「字形可参考」而非定真依据  

顾景舟**不同时期印章不同**，单凭「顾景舟制」四字不能定真；须与盖内、把款配套互证。

### 4. 流传与市场逻辑

- 真品多流传有序：名家弟子、早期藏家、港台回流、主流拍卖（嘉德、保利、西泠等）
- 闲鱼/地摊/「山东馆直营」+ 景舟款 = **极高仿品或臆造风险**
- 顾景舟代表作拍卖价通常**数十万至数千万人民币**；低价「捡漏」违背市场规律

### 5. 输出鉴定结论（固定格式）

```markdown
## 鉴定结论
- **真伪倾向**：真品 / 疑伪 / 高仿 / 无法仅凭图片判定
- **置信度**：高 / 中 / 低（说明限制）
- **推断年代**：（若可）
- **风险等级**：P0 极高风险 / P1 高风险 / P2 中风险 / P3 低风险

## 支持依据（分条，引用图部位）
## 疑点与反证
## 建议下一步（机构、检测项、需补拍角度）
## 免责声明
```

## 顾景舟风格速记

- **造型**：古朴典雅，线条流畅含蓄；方器功底深，圆器比例精到；讲究「形、神、气」。
- **工艺**：流、把、钮与身筒过渡自然，无突兀接痕；盖口严密；出水顺畅；内壁整洁。
- **书法**：本人书法功底深，刻款遒劲连贯；晚期常与吴湖帆、江寒汀等合作书画，需核对合作者风格。
- **泥料**：胎骨坚致，色泽温润；各时期泥色有差异，但无贼光、无均匀「塑料感」。

## 常见仿品特征（一眼疑伪）

1. 同款图片铭文前后不一致（爱客/爱莲/爱宠等混用）
2. 印章字体呆板、深浅不均、布局与馆藏真品不符
3. 工艺粗糙：接痕生硬、出水孔大小不一且排列随意
4. 人为做旧：口沿黑渍过匀、泥色发闷
5. 来源不可信 + 名款 + 低价

## 禁止事项

- 不凭单张图给出「绝对真品」结论
- 不估价到具体万元（可给市场量级与参考拍卖区间，并注明波动）
- 不替用户联系买卖或背书交易平台
