# 珍爱网 APP 业务 · 最快上市路径与执行计划

> 立项日 T0：2026-06-02
> 目标：以最干净的 APP 业务为主体，按现行监管规则，以"最快且可成"为原则推进首次公开发行（IPO）。
> 文档密级：内部决策稿（对外披露需另行合规过滤）

---

## 0. 一页纸结论（决策摘要）

| 项目 | 结论 |
|---|---|
| **上市地** | 港股主板（红筹架构 + 直接发行） |
| **上市标准** | 主板「盈利测试」——三年累计股东应占盈利 ≥ 8000 万港元（最近一年 ≥ 3500 万、前两年合计 ≥ 4500 万），上市时市值 ≥ 5 亿港元 |
| **达标判断** | APP 业务年利润约 1.2 亿元 ≈ 1.3 亿港元/年，**单年即超门槛，三年累计超额一倍以上**，财务非约束项 |
| **关键路径长杆** | ①数据合规 / 网络安全审查自评估；②业务聚焦后的"持续经营口径"三年财务重塑 |
| **最快可成时点** | 立项后约 **8–9 个月**（激进并行）；稳健 **10–12 个月**（详见时间表） |
| **预估市值区间** | 约 18–24 亿元人民币（按年利 1.2 亿、15–20 倍 P/E 中性测算） |
| **现金流红线** | IPO 战略价值在于"合规背书 + 现金安全垫 + 并购货币化"，不为冲高估值烧增长预算 |

**为什么是港股，不是 A 股 / 美股：**
- **A 股**：婚恋/交友 To C 平台的"板块定位"与舆情审查不友好，且当前发行节奏受控、排队周期不可控，与"最快"目标冲突。
- **美股**：掌握超 100 万用户敏感个人信息的平台赴美，网络安全审查近乎必触发，叠加中美审计（PCAOB）与地缘风险，性价比最低。
- **港股主板**：财务门槛对我们是"超额满足"；备案制通道畅通（在途 274 家、赴港 224 家）；可用"秘密递交"降低市场波动暴露——是唯一兼顾"快"与"能成"的选项。

## 1. 最快上市时间表（核心交付物）

> 以"立项日 T0 = 2026-06-02"为锚点，按**关键节点**排序（非日历承诺）。
> 核心加速逻辑：**最长杆（数据合规 + 财务重组）在 T0 当月并行启动**，而非串行排队。

### 1.1 阶段甘特图（激进并行口径，最快约 8–9 个月）

| 阶段 | 时间窗（T0 起） | 指示日历（若 T0=2026-06） | 关键里程碑 |
|---|---|---|---|
| **P0 立项 · 三大长杆并行启动** | T0 ~ T0+1 月 | 2026-06 | 中介初步遴选；数据合规自评估启动；审计师进场定调重组口径；红筹/VIE 架构方案确认 |
| **P1 合规整改 + 财务重塑** | T0+1 ~ T0+3 月 | 2026-07 ~ 2026-09 | 数据合规整改落地 + 网络安全审查自评估结论；三年"持续经营口径"审定报表；外汇/ODI/税务历史沿革合规 |
| **P2 中介定稿 + 证监会备案** | T0+3 ~ T0+5 月 | 2026-09 ~ 2026-11 | 招股书初稿；提交证监会境外上市备案；20 个工作日办结（补充材料不计时） |
| **P3 港交所递表 + 聆讯** | T0+5 ~ T0+7 月 | 2026-11 ~ 2027-01 | A1 递表（可秘密递交）；监管问询多轮回复；通过上市聆讯 |
| **P4 路演 + 定价 + 挂牌** | T0+7 ~ T0+9 月 | 2027-01 ~ 2027-03 | 路演、簿记建档、定价；**挂牌上市** |

**最快目标挂牌窗口：2027 年第一季度末 ~ 第二季度初。**

### 1.2 里程碑检查点（Milestone Gate）

- **Gate 1（T0+1 月）**：四方中介（保荐人、申报会计师、内地+香港律师、数据合规顾问）到位 → 否则全局顺延。
- **Gate 2（T0+3 月）**：网络安全审查自评估出具书面结论 + 审计师确认重组口径可审 → **这是整条路径的"死亡之谷"，过不了则递表无意义**。
- **Gate 3（T0+5 月）**：证监会备案受理。
- **Gate 4（T0+7 月）**：通过港交所聆讯。
- **Gate 5（T0+9 月）**：挂牌。

### 1.3 时间表的三个前提（决定能否跑到"最快"）

1. **数据合规自评估在 P0 当月即开工**——这是最长杆，晚一个月，整体晚一个月。
2. **审计师在 P0 即介入定调"持续经营口径"**——业务聚焦造成的财务断点，越早处理越不会在聆讯被反复问询。
3. **不触发完整网络安全审查**——若自评估认定影响国家安全须正式申报，整体周期将额外增加数月（详见第 6 节风险与 Plan B）。

## 2. 关键路径两大长杆（决定快慢的根因）

### 长杆 A · 数据合规 / 网络安全审查（最高优先级）
- 珍爱网用户规模必然 > 100 万，且为婚恋强敏感个人信息（身份、收入、影像、聊天记录）。
- 赴港上市须自评估"是否影响国家安全"，必要时于递表前主动申报网络安全审查。
- 证监会对赴港 App 企业的标准问询原话：*"收集及储存的用户信息规模、数据收集使用情况、是否向第三方提供个人信息、上市前后个人信息保护和数据安全的安排"*。
- **不提前完成，财务再好也递不进去。** 必须第一个启动（详见第 3 节自查清单）。

### 长杆 B · 业务聚焦后的"财务连续性"
- 业务聚焦（出清人工与高风险业务线）在合规上是**最强加分项**，但会计上形成"业务重组/不连续"。
- 港股主板要求"三年同一管理层、同一业务"的连续记录。
- **解法**：以**持续经营口径（continuing operations）**重塑保留 APP 业务三年报表，关停业务列为"已终止经营"剥离（详见第 5 节框架）。

## 3. 数据合规 / 网络安全审查自查清单（可执行）

> 建议责任主体：技术总监（王溢文）牵头，数据总负责（曾伟）配合；外聘数据合规顾问出具评估意见。
> 原则：**弱依赖、强闭环**——以技术与数据团队为主自行推动，不依赖外部支持部门大规模配合。

| # | 自查项 | 目标状态 | 状态 |
|---|---|---|---|
| 1 | 用户个人信息规模盘点（注册量、活跃量、敏感字段清单） | 形成书面台账，明确是否 > 100 万 | 待启动 |
| 2 | 个人信息收集"最小必要"合规审查 | 逐项比对收集目的与必要性，删除冗余采集 | 待启动 |
| 3 | 隐私政策 / 用户协议合规复核（PIPL 口径） | 单独同意、撤回机制、未成年人保护齐备 | 待启动 |
| 4 | 第三方共享 / SDK 数据流向梳理 | 明确是否向第三方提供个人信息及合规依据 | 待启动 |
| 5 | 数据出境评估（如有跨境传输） | 完成出境安全评估/标准合同备案 | 待启动 |
| 6 | 数据分级分类与加密、留存、删除机制 | 建立分级制度 + 技术加密 + 留存期限 | 待启动 |
| 7 | 数据安全应急预案与历史泄露事件复盘 | 形成预案，确认无重大未披露事件 | 待启动 |
| 8 | 关键信息基础设施（CIIO）认定判断 | 明确是否被认定，对应义务清单 | 待启动 |
| 9 | **网络安全审查必要性自评估书面结论** | 出具是否需主动申报的法律/合规意见 | 待启动（Gate 2 关口） |
| 10 | 上市前后个人信息保护安排说明 | 形成可直接回应证监会问询的说明文件 | 待启动 |

## 4. 中介机构候选清单 + 比价询价框架

> 原则：保荐人定方向、会计师定财务口径、律师定合规架构、数据顾问拆长杆。四方 T0 当月必须并行接洽。

### 4.1 角色与遴选要点

| 角色 | 职责 | 遴选要点 | 候选类型 |
|---|---|---|---|
| **保荐人（券商）** | 统筹申报、聆讯、发行 | 港股消费/互联网项目过往业绩、聆讯通过率、承销网络 | 头部中资券商港股投行部 / 国际投行 |
| **申报会计师** | 三年审计 + 持续经营口径重塑 | To C 互联网收入确认经验、重组业务剥离经验 | 四大会计师事务所 |
| **内地律师** | 备案、红筹搭建、外汇/ODI/税务合规 | 证监会备案过会经验、数据合规协同 | 头部内资所证券团队 |
| **香港律师** | 上市规则、招股书、聆讯 | 主板项目数量、与联交所沟通经验 | 香港本地资本市场所 |
| **数据合规顾问** | 网络安全审查自评估、PIPL 整改 | App 数据合规专项、网信办沟通经验 | 专业数据合规律所/咨询 |

### 4.2 比价询价框架（统一发问，便于横向对比）

向各候选机构统一询价以下要素：
1. 同类（港股消费互联网、含业务重组）项目近 3 年案例与结果；
2. 报价结构：固定费 + 成功费（按募资比例）+ 实报实销上限；
3. 团队配置：项目合伙人是否亲自带队、核心成员投入度；
4. 时间承诺：各自环节最快交付节点（用于回填本时间表）；
5. 风险点预判：对方对我方"业务重组连续性""数据合规"两大长杆的初判与应对方案。

## 5. 财务重组「持续经营口径」拆分框架

> 建议责任主体：公司财务负责人（待指定）+ 申报会计师；T0 当月启动。

**核心原则：** 把保留的 APP 业务做成"独立、可比、连续三年"的财务主体，关停业务作为"已终止经营"清晰剥离。

| 步骤 | 动作 | 产出 |
|---|---|---|
| S1 | 划定持续经营主体边界（保留 APP 业务的法人/资产/人员/合同） | 业务边界界定备忘 |

## 6. 估值、募资与风险

### 6.1 估值与募资预期（守现金流红线）
- 港股婚恋/社交 App 估值通常 12–25 倍 P/E；按年利 1.2 亿、中性 15–20 倍，**市值约 18–24 亿元人民币**，属中小盘。
- 含义：①不为冲高估值烧品牌/获客预算——华而不实的增长投放会同时打掉利润和利润率，反压估值；②IPO 战略价值在"合规背书 + 现金安全垫 + 并购货币化"，非一次性大额融资。账上现金安全永远第一。
- **最强叙事 = 已完成的事实**：主动业务聚焦、只留最干净的 App、市场口碑好、稳定盈利——"主动合规化、轻资产、可持续盈利"本身就是估值溢价来源。

### 6.2 风险与 Plan B

| 风险 | 影响 | 应对 |
|---|---|---|
| 网络安全审查自评估认定须正式申报 | 周期额外增加数月 | 提前整改把风险降至"无需申报"区间；最坏情形预留申报时间窗，时间表顺延而非推翻 |
| 业务重组导致财务连续性被反复问询 | 聆讯延误 | T0 即让审计师定调持续经营口径，预先备好披露说明 |
| 红筹架构外汇/ODI/税务历史瑕疵 | 备案受阻 | 内地律师 T0 即做历史沿革合规核查，出具结论性意见 |
| 市场窗口波动 | 定价折让 | 用"秘密递交"灵活择时，准备就绪后再公开 |
