## 二、东郊到家模式事实基准（2026-07调研，公开资料）

- 2018年成立于重庆，覆盖47城，注册用户1000万+，签约技师3万+
- 零门店轻资产；技师办个体工商户执照、签《合作协议》，平台无社保/底薪义务，责任隔离在个体
- 平台只与个人签约，不允许机构入驻
- 阶梯佣金（15天周期）：流水0-6500技师分50% → 6500+分55% → 9500+（叠加续购率/成长值门槛）60-70% → 14500+分80%；平台抽佣20%-50%
- 四端系统：用户端/技师端/商家端/管理后台；按位置/技能/时间智能派单
- 城市运营中心承担区域扩张与技师招募维护（4年22城28中心）
- 裂变增长：技师/用户皆可做推广合伙人
- **已暴露的坑（蓝图必须内置对策）**：①飞单绕过平台 ②技师关系松散易流失 ③签约执照缺失/名实不符被曝光 ④诱导办卡/退款难投诉 ⑤考核变形（加钟包装成续购）

## 三、珍爱网蓝图核心参数（赵总决断前的建议口径）

### 3.1 四层架构
平台总部（五大中台：流量/派单算法/结算分佣/品控风控/培训认证 + 四端系统）→ 直营区域运营中心 → 个体红娘网络 → 单身用户。
两条主线：管理链自上而下；**资金流只走平台**（任何一层不得线下收款）。

### 3.2 区域运营中心（直营）
- 定位：「管红娘的人，不碰用户的钱」；四管（招募/培训督导/属地品控/服务考核）四不管（不收款/不签约/不自建场所/不干预派单）
- 编制：单城4-6人（中心长1+招募官1-2+培训督导1-2+品控1），管100-300名红娘，杠杆1:40
- 考核：红娘月活跃率≥60%、平均服务分≥4.5、千单投诉率≤3‰、红娘90天留存率≥70%

### 3.3 个体红娘
- 入驻五步：实名背景核验→资质认证→个体户注册（运营中心协办）→签合作协议→培训考核开通接单
- 资质前台公示（执照+证书+实名+服务分）——修正东郊执照乱象
- 服务SKU按次计费：精准牵线¥199-399/次、约会策划¥299-599/次、情感咨询¥199-499/时、形象优化¥99-299/次、月度套餐¥999-2999/月（可随时取消）
- 客单价熔断线：单用户单月消费超¥6,000触发复核+冷静期（防诱导消费）
- 接单：智能派单为主+抢单池保新人+指定复购

### 3.4 阶梯分成（月度考核周期）
| 档位 | 月流水 | 红娘分成 | 门槛 |
|---|---|---|---|
| 起步档 | 0-2万 | 50% | 岗前认证 |
| 达标档 | 2-4万 | 55% | 服务分≥4.5 |
| 优秀档 | 4-8万 | 60% | 服务分≥4.6 + 复购率≥20% |
| 标杆档 | 8万+ | 70% | 服务分≥4.7 + 复购率≥25% |

- 平台抽佣30%-50%；单城佣金收入须覆盖运营中心成本1.5倍方可开城
- 复购率=用户真实复购（排除东郊式"加钟包装成续购"的考核变形）
- 违规降档；飞单一票清退+黑名单；推荐返佣2%-5%裂变获客

### 3.5 防飞单三重防线
① 虚拟号+客户资料脱敏 ② 高档位分成让头部红娘留在平台更赚 ③ 清退+黑名单；试点期观测"飞单率"，超5%重新校准分成

### 3.6 路线图
试点（1-4月，深圳/重庆1-2城，50-100名红娘，四端MVP）→ 验证（5-8月，单城盈利+《开城手册》）→ 复制（9-18月，8-12城）→ 规模（19-36月，红娘破万、算法派单≥80%、品类第一）

## 四、与六条经营红线的契合关系

| 红线 | 契合点 |
|---|---|
| 现金流红线 | 零门店轻资产；按次收费T+7结算；试点小额验证先子弹后炮弹 |
| 风险隔离 | 履约责任在个体户层面；与门店SaaS隔离/邀约外包化同一风险哲学 |
| 弱依赖强闭环 | 平台自闭环，不依赖支持部门大规模配合 |
| 反鞭打快牛 | 单量靠算法与激励驱动，非行政加压；抢单池保障中腰部 |
| 审计视角 | 全流程线上留痕，飞单/品控数据可度量 |
| 高客单逼签禁令 | 按次小额计费+熔断线+冷静期，从机制上消灭逼签 |
